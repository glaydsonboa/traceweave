# Licensing Scope

Traceweave currently includes material released under the repository's Apache License 2.0.

## Existing public material

Material already published in this repository under Apache-2.0 remains available under those terms.

This documentation update does not attempt to revoke or retroactively narrow rights already granted to public v0.1 material.

## Future public material

Files intentionally added to this repository are expected to follow the repository's stated license unless a file or release explicitly states otherwise.

## Separate private or commercial software

The existence of an open protocol and an Apache-2.0 reference demonstration does not automatically license software that is:

- developed separately;
- not distributed in this repository;
- private;
- commercial;
- governed by another explicit license or agreement.

## No automatic scope expansion

A public specification describes semantics and interoperability expectations.

It does not, by itself, transfer rights to unpublished source code, private infrastructure, trademarks, private datasets or separate commercial implementations.

This document clarifies repository scope; it is not a replacement for the `LICENSE` file.
