# Questions & reproducibility review

This page is the public entry point for questions about the Agent Self-Report Evidence track.

Ask questions in:

**[GitHub Issue #5 — Questions & reproducibility review](https://github.com/glaydsonboa/traceweave/issues/5)**

## What can be challenged

Reviewers can ask for:

- the primary source behind a claim;
- the human intervention that preceded an agent action;
- the difference between narrated and executed state;
- the runtime or Git artifact that supports an execution claim;
- the timestamp, UUID or hash for a preserved event;
- the source of a correction or retraction;
- an alternative explanation for a promoted case;
- the evidence class assigned to a source;
- the reason a candidate was promoted, rejected or left uncertain.

## Response rule

Answers should prefer preserved evidence over recollection.

Where the evidence does not establish a point, the response should say so.

## Current discussion anchor

The latest provenance publication is:

- [Fable causal lineage — human direction, night work and agent observability](provenance/fable-causal-lineage.md)

That note preserves a sequence in which the human operator introduces a direction, an assistant formalizes it, working-schedule constraints affect the operational choice, a provider failure makes the direction actionable, and later Fable documents formalize attribution and audit rules.

The objective is to keep causal authorship, execution, observation and later narration separate.
